# Archived Chrome extension

This directory contains the complete Headrush Companion Chrome extension version 1.60 that previously lived at the repository root.

Archived files include the Manifest V3 service worker, content script, side-panel UI, icons, and Chrome Web Store metadata. Nothing was deleted; moving these files back to the repository root restores the previous source layout.

The archive is retained as a behavioral reference for local-device discovery, proxying, and any workflows that may be useful in the planned Tauri application. It should not be used as the foundation of the new application architecture.
