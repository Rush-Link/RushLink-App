# RushLink by Cygma Audio — privacy

RushLink is developed by Cygma Audio.

RushLink does not include analytics, advertising SDKs or crash-reporting telemetry. Application preferences, StageHand layouts, favourites, Test Rig templates, cached catalogue data and rig history are stored in the local application profile on the user's computer.

When connected, RushLink communicates with the HeadRush device selected by the user over the local network. Tone3000 and HeadRush Cloud requests are made through capabilities exposed by the connected device. Creating or importing a RushLink backup happens only after the user chooses a local file.

The separately maintained public website has its own [privacy information](https://rush-link.github.io/privacy.html).

RushLink is early-alpha software. Users should avoid including sensitive information in rig, setlist, stage or preset names and should review backup files before sharing them.
