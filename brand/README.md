# RushLink brand pack

The RushLink mark uses the complete name, stacked as **RUSH** over **LINK**, with angled signal cuts. Use the full app icon for avatars, stores and product tiles. Use the transparent mark on controlled dark backgrounds.

## Folders

- `master/` — editable SVG masters for the icon, transparent mark and stacked wordmark.
- `png/` — square application and communication icons from 16 to 1024 pixels, plus a transparent mark.
- `platform/` — Windows ICO, macOS ICNS, and complete generated iOS and Android icon sets.
- `social/` — ready-to-use 400, 512, 800 and 1024 pixel avatars and a 1200×630 social card in SVG and PNG.

## Included square sizes

`16`, `20`, `24`, `29`, `32`, `40`, `48`, `50`, `57`, `58`, `60`, `64`, `72`, `76`, `80`, `87`, `96`, `114`, `120`, `128`, `144`, `152`, `167`, `180`, `192`, `256`, `310`, `400`, `512`, `800`, and `1024` pixels.

Use the smaller files for favicons and interface chrome, 180/192 for mobile shortcuts, 256/310 for Windows tiles, and 400 pixels or larger for profiles and communication artwork.

## Clear space and minimum size

Keep clear space equal to one cable width around the mark. Use the complete icon at 32 px or larger. Below 32 px, use `png/rushlink-icon-16.png` or `png/rushlink-icon-24.png`, which were rasterized from the same simplified master.

## Colours

- Signal cyan: `#61E8E5`
- Link blue: `#58A8FF`
- Rush violet: `#9B78FF`
- Deep canvas: `#05080D`
- Light wordmark: `#F2F6FA`

Do not add extra glow, stretch the mark, recolour individual cable sections, or place the transparent mark on a visually busy background.
